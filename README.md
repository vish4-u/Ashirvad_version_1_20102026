# Aassheervaad – Your Digital Partner

Static website (single `index.html`, no build step).

## Publish on GitHub Pages
1. Create a new GitHub repository and upload these files (or `git push`).
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder `/ (root)`.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
4. Custom domain: add it under Settings → Pages and point DNS to GitHub.

## Things to edit in index.html
- Team section: CEO, HR and team member names, bios, emails.
- Contact form: replace `YOUR_FORM_ID` with your Formspree ID.
- Email `hello@ashirvaad.in`.
